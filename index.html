❓ Frequently asked questions

Is ReelKit free?
These browser-based tools are free to use. Hosting and third-party API terms can change.

Why doesn't the site automatically fetch every Instagram caption?
Instagram restricts automated access. Automatic extraction requires an authorized API or a reliable provider. This starter version does not claim to extract data it cannot access.

Can I use it on my phone?
Yes. The page is responsive and works in a modern mobile browser.

Does it download videos?
No. The media helper only opens the source URL. Only download content you own or are authorized to save, using permitted methods.

ReelKit is an independent project and is not affiliated with Instagram or Meta.
